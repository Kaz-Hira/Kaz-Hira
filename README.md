### 公開しているもの

**🎞 LookRack** — Mac 向けの RAW 現像アプリ(ソースは非公開)

調整を**プラグインとして配る**RAW現像アプリです。プリセットが「固定の数値の束」なのに対して、
LookRack のレンズプロファイルは**その写真の EXIF(焦点距離・絞り)で補間されます**。
同じルックを別のレンズで撮った写真に当てても、破綻しません。

- Swift + Metal + C++ interop(LibRaw)/ **約3万行・テスト317件**
- ACEScg の scene-referred パイプライン。色行列は定数を貼らず、**原色xyから導出して自己整合で検算**
- 段キャッシュでプレビュー **p50 2.9ms**
- `ProcessVersion` を持つので、**過去の編集を当時の絵のまま再現**できる
- 書き出しで失われるものを名指しする `LossReport`(8bitに落ちる・JPEGで捨てる、を黙ってやらない)

### 測ってから決めています

| 実測 | 分かったこと |
|---|---|
| 自分のVaultのノートの **72.8%** が一度も読み返されていなかった | AIはノートを作るのを速くするが、読み返すのは速くしない。**生成過剰・消費不足** |
| Claude Code のトークン消費の **96.3%** が cache read(過去文脈の読み直し) | 出力は0.5%未満。**CLAUDE.md を削っても効かない**。効くのはセッションを切ること |
| 導入したエージェントツール3つの実使用が**ほぼゼロ**(生涯メッセージ1通) | **人間が手で起動するツールは続かない**。走っているセッションから呼べるものが残る |

いずれも「そうだと思っていたこと」が実測で外れた例です。Zenn に書いています。
